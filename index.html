Fundamentos de Programación, paso a paso

Ocho conceptos, en el orden en que conviene aprenderlos. Cada paso se apoya en el anterior: lee la explicación, escribe el ejemplo en tu computadora, cámbialo y observa qué pasa. Los ejemplos usan Python porque se lee casi como español.

1Algoritmos: pensar antes de escribir

Un algoritmo es una lista ordenada de pasos para resolver un problema. Programar es escribir ese algoritmo en un lenguaje que la computadora entienda.

Ejemplo cotidiano: preparar una taza de té.

1. Hervir agua
2. Poner la bolsa de té en la taza
3. Verter el agua en la taza
4. Esperar 3 minutos
5. Retirar la bolsa
Idea clave: un buen algoritmo es preciso (sin ambigüedades), ordenado y finito (termina). Si cambias el orden de los pasos, el resultado cambia.

Las tres partes de casi todo programa

Entrada (los datos que recibe) → Proceso (lo que hace con ellos) → Salida (el resultado que muestra).

2Variables y tipos de datos

Una variable es una caja con nombre donde guardas un dato para usarlo después.

nombre = "Ana"
edad = 19
promedio = 8.7
es_estudiante = True

El signo = no significa "es igual" sino "guarda este valor en esta variable". Se lee de derecha a izquierda.

TipoQué guardaEjemplo
intNúmeros enteros25, -3
floatNúmeros con decimales3.14
strTexto (cadena)"Hola"
boolVerdadero o falsoTrue, False

Reglas para nombrar variables

  • Usa nombres que expliquen el contenido: precio_total, no x.
  • No empieces con número ni uses espacios; usa guion bajo.
  • Python distingue mayúsculas: edad y Edad son variables distintas.

Lógicos

and (se cumplen ambas), or (se cumple al menos una), not (invierte el resultado).

edad = 20
print(edad >= 18 and edad < 65)
True
Error común: = guarda un valor, == compara dos valores. Confundirlos es el error de principiante más frecuente.

El residuo % sirve para saber si un número es par: si n % 2 == 0, es par.

4Entrada y salida de datos

print() muestra información en pantalla. input() pide un dato al usuario y lo devuelve siempre como texto.

nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))
print("Hola", nombre, "; el año que viene tendrás", edad + 1)
¿Cómo te llamas? Ana ¿Cuántos años tienes? 19 Hola Ana ; el año que viene tendrás 20

Observa int(...): convierte el texto a número entero. Sin esa conversión, edad + 1 daría error porque no se puede sumar un texto con un número. Usa float(...) si el dato puede tener decimales.

Con una f-string puedes insertar variables dentro del texto:

print(f"Hola {nombre}, tienes {edad} años")

5Condicionales: tomar decisiones

Un condicional ejecuta código solo si se cumple una condición.

calificacion = float(input("Calificación: "))

if calificacion >= 9:
    print("Excelente")
elif calificacion >= 6:
    print("Aprobado")
else:
    print("Reprobado")
Calificación: 7.5 Aprobado
  • if: se evalúa primero.
  • elif (opcional, puede haber varios): se evalúa solo si las anteriores fallaron.
  • else (opcional): se ejecuta si nada de lo anterior se cumplió.
Importante: los dos puntos : y la sangría (4 espacios) son obligatorios. La sangría le dice a Python qué líneas pertenecen al bloque.

6Ciclos: repetir sin copiar y pegar

for: cuando sabes cuántas veces repetir

for i in range(1, 6):
    print("Vuelta", i)
Vuelta 1 Vuelta 2 Vuelta 3 Vuelta 4 Vuelta 5

range(1, 6) genera 1, 2, 3, 4, 5. El límite superior no se incluye.

while: mientras una condición sea verdadera

clave = ""
while clave != "1234":
    clave = input("Clave: ")
print("Acceso concedido")
Cuidado con el ciclo infinito: dentro de un while algo debe cambiar para que la condición llegue a ser falsa. Si no, el programa nunca termina (detenlo con Ctrl + C).

Patrón útil: acumulador

suma = 0
for n in range(1, 11):
    suma = suma + n
print("La suma del 1 al 10 es", suma)
La suma del 1 al 10 es 55

7Funciones: bloques reutilizables

Una función agrupa instrucciones bajo un nombre para usarlas cuantas veces quieras. Recibe parámetros (entrada) y puede devolver un resultado con return.

def area_rectangulo(base, altura):
    return base * altura

print(area_rectangulo(5, 3))
print(area_rectangulo(10, 2))
15 20
  • Se define una vez con def y se llama las veces necesarias.
  • return entrega el resultado y termina la función.
  • Las variables creadas dentro de una función solo existen dentro de ella (alcance local).
Buena práctica: cada función debe hacer una sola cosa y tener un nombre que diga cuál es.

8Listas: muchos datos en una variable

Una lista guarda varios valores ordenados. Cada uno tiene una posición (índice) que empieza en 0.

calificaciones = [8, 9, 6, 10]

print(calificaciones[0])      # primer elemento
calificaciones.append(7)      # agrega al final
print(len(calificaciones))    # cantidad de elementos

for nota in calificaciones:
    print(nota)
8 5 8 9 6 10 7

Combinando ciclos y listas ya puedes calcular un promedio:

promedio = sum(calificaciones) / len(calificaciones)
print(f"Promedio: {promedio}")
Promedio: 8.0

9Práctica final

Intenta cada ejercicio por tu cuenta antes de abrir la solución. Equivocarte y corregir es parte del aprendizaje.

Ejercicio 1: ¿es par o impar?

Pide un número y muestra si es par o impar. (Temas 4 y 5)

Ver solución 
n = int(input("Número: "))
if n % 2 == 0:
    print("Par")
else:
    print("Impar")

Ejercicio 2: tabla de multiplicar

Pide un número y muestra su tabla del 1 al 10. (Temas 4 y 6)

Ver solución 
n = int(input("Tabla del: "))
for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")

Ejercicio 3: promedio con función

Crea una función promedio(lista) que devuelva el promedio de una lista de calificaciones y úsala con tres notas que pida al usuario. (Temas 4, 6, 7 y 8)

Ver solución 
def promedio(lista):
    return sum(lista) / len(lista)

notas = []
for i in range(3):
    notas.append(float(input("Nota: ")))

print("Promedio:", promedio(notas))

Para cuando algo no funciona

  • Lee el mensaje de error de abajo hacia arriba: la última línea dice qué pasó y la anterior, dónde.
  • SyntaxError: falta un símbolo (:, paréntesis o comillas).
  • NameError: escribiste mal el nombre de una variable o la usaste antes de crearla.
  • IndentationError: la sangría no es consistente.
  • TypeError: mezclaste tipos, por ejemplo texto con número.
  • Usa print() para ver el valor de tus variables en cada paso.
